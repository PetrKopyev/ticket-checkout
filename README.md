# Оформление билетов

Интерфейс покупки билетов на мероприятие на моковых данных (тестовое задание Sqoch, «Тест 01»).
React 19 + TypeScript + Vite + Tailwind 4, тесты на Vitest. Бэкенда нет.

## Запуск

```
npm install
npm run dev      # http://localhost:5173
npm test         # правила заказа и мок-API
npm run build    # проверка типов и сборка
```

Нужен Node 20+.

## Как это устроено

Три шага: участники → проверка → результат.

- `src/rules.ts` — все правила в чистых функциях: цена по возрасту, итог, валидация участника, email и заказа.
- `src/api.mock.ts` — моковые места (10 штук) и `confirmOrder` с задержкой 400 мс. Места перепроверяются в момент подтверждения.
- `src/App.tsx` — шаг, участники, email, результат.
- `src/components/` — экраны `ParticipantsStep`, `ReviewStep`, `ResultStep` и итог заказа `OrderSummary`.

Правила из задания:

- Полный билет 2000 ₽ (от 14 лет), детский 1000 ₽ (младше 14).
- От 1 до 4 участников; у каждого имя и возраст, один email на заказ.
- Ребёнок младше 14 допускается только с участником от 18 лет в том же заказе. Участник 14–17 лет платит полный билет, но сопровождающим не считается.

Допущения: число детей на одного взрослого не ограничено (в задании нет); возраст — целое от 0 до 120; email проверяется простым шаблоном.

## Как показать «места закончились»

Внизу страницы есть демо-панель (на всех шагах):

1. Заполните заказ и дойдите до шага «Проверка».
2. Нажмите «Демо: кто-то купил билеты» (мест станет 0) или «Демо: осталось 1 место».
3. Нажмите «Подтвердить» — увидите «Места закончились» либо «Осталось мест: 1, а в заказе N».
4. «Сбросить демо» возвращает 10 мест.
